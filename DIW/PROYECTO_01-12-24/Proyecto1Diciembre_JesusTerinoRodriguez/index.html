Bienvenido al Manual

Este manual está diseñado para guiarte paso a paso en la instalación y configuración de tres de los servidores más importantes para aplicaciones empresariales en Java EE: Apache Tomcat, WildFly y GlassFish. Cada servidor tiene características únicas que los hacen adecuados para diferentes tipos de proyectos. Aquí encontrarás información detallada para comenzar desde cero, incluyendo requisitos, pasos de instalación y configuraciones avanzadas.

¿Qué es Java EE?

Java Platform, Enterprise Edition (Java EE) es una plataforma robusta y escalable para el desarrollo de aplicaciones empresariales en Java. Proporciona un conjunto de especificaciones y servicios que simplifican el desarrollo de aplicaciones distribuidas y basadas en la web. Java EE es ideal para proyectos que requieren:

  • Escalabilidad para manejar grandes cantidades de usuarios simultáneos.
  • Interoperabilidad con otros sistemas y servicios.
  • Soporte para estándares empresariales como EJB, JPA y JAX-RS.

¿Por qué elegir estos servidores?

La elección del servidor adecuado es crucial para el éxito de tu proyecto. Este manual cubre tres servidores populares que ofrecen un equilibrio entre simplicidad, funcionalidad y rendimiento:

  1. Apache Tomcat: Un servidor ligero y fácil de usar, ideal para proyectos pequeños y medianos. Tomcat soporta tecnologías básicas de Java como Servlets y JSP, lo que lo hace perfecto para aplicaciones web estándar.
  2. WildFly: Un servidor altamente configurable y orientado a aplicaciones empresariales. Ofrece soporte para especificaciones avanzadas de Java EE como EJB, JPA y JMS.
  3. GlassFish: El servidor de referencia para Java EE, conocido por su compatibilidad completa con todas las especificaciones y su robustez en aplicaciones empresariales.

¿Qué aprenderás?

En este manual, aprenderás a instalar, configurar y personalizar cada uno de estos servidores. Además, obtendrás consejos prácticos para optimizar su uso y sacar el máximo provecho de sus características.

  • Cómo preparar tu entorno de desarrollo con las herramientas necesarias.
  • Los pasos detallados para instalar cada servidor.
  • Configuraciones avanzadas para mejorar el rendimiento y la seguridad.
  • Cómo desplegar aplicaciones web en cada servidor.

¿A quién va dirigido este manual?

Este manual está pensado para desarrolladores de todos los niveles, desde principiantes hasta expertos. Si eres un estudiante, profesional o simplemente alguien interesado en aprender sobre servidores Java EE, este manual te será útil. No se requieren conocimientos previos avanzados, aunque algo de familiaridad con Java será de ayuda.

Recomendaciones antes de comenzar

Antes de adentrarte en la configuración de los servidores, asegúrate de cumplir con los siguientes requisitos:

  • Tener instalado un JDK compatible (se recomienda JDK 11 o superior).
  • Familiaridad básica con la línea de comandos de tu sistema operativo.
  • Acceso a una conexión a internet para descargar los paquetes necesarios.
  • Una comprensión general del ciclo de vida de las aplicaciones web.

Con todo listo, ¡comencemos este emocionante recorrido hacia la configuración de tus servidores Java EE!

Apache Tomcat

Apache Tomcat es un contenedor ligero de servlets que soporta tecnologías Java como Servlets y JSP (Java Server Pages). Es ampliamente utilizado en aplicaciones web de pequeña y mediana escala debido a su simplicidad y velocidad.

Requisitos previos

  • Java Development Kit (JDK): Asegúrate de tener instalado el JDK 11 o superior. Puedes instalarlo con el siguiente comando: 
    • sudo apt install openjdk-11-jdk
  • Variable de entorno JAVA_HOME: Configura JAVA_HOME en tu archivo

    ~/.bashrc

    con: 
    • export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64

Pasos de Instalación

  1. Descarga Tomcat: Ve al sitio oficial de Apache Tomcat y descarga la última versión de Tomcat. 
    2. wget https://downloads.apache.org/tomcat/tomcat-10/v10.0.30/bin/apache-tomcat-10.0.30.tar.gz
  2. Descomprime y configura:
    3. tar -xvzf apache-tomcat-10.0.30.tar.gz
    sudo mv apache-tomcat-10.0.30 /opt/tomcat
  3. Establece permisos: Asegúrate de que todos los scripts sean ejecutables. 
    4. sudo chmod +x /opt/tomcat/bin/*.sh
  4. Inicia Tomcat: Lanza el servidor Tomcat con:
    5. /opt/tomcat/bin/startup.sh
  5. Accede a la consola: Visita

    http://localhost:8080

    en tu navegador.

Configuraciones Avanzadas

Una vez que Tomcat esté instalado, puedes personalizarlo para que se ajuste mejor a tus necesidades:

  • Usuario administrador: Para gestionar el servidor desde la web, edita el archivo

    conf/tomcat-users.xml

    y añade las siguientes líneas: 
    • role rolename="manager-gui"
    user username="admin" password="password" roles="manager-gui"
  • Despliegue de aplicaciones: Copia los archivos

    .war

    en el directorio

    webapps

    de Tomcat. Al reiniciar el servidor, Tomcat desplegará automáticamente las aplicaciones.

WildFly

WildFly es ideal para aplicaciones empresariales, compatible con EJB, JPA y muchos servicios distribuidos. Ofrece una mayor flexibilidad y escalabilidad para proyectos grandes.

Requisitos previos

  • Java JDK: Instala el JDK más reciente desde Oracle o usa una distribución abierta como OpenJDK.
  • Configuración del PATH: Asegúrate de configurar la variable

    JAVA_HOME

    correctamente y añadirla al

    PATH

    .

Pasos de Instalación

  1. Descarga WildFly: Dirígete a la página de WildFly y descarga la última versión. 
    2. unzip wildfly-x.y.z.zip -d C:/WildFly
  2. Inicia el servidor: Abre una terminal y navega al directorio

    /bin

    de WildFly. Luego, ejecuta: 
    3. cd C:/WildFly/bin
standalone.bat
  3. Accede a la consola: Abre el navegador y accede a la consola administrativa en

    http://localhost:9990

    .

Configuraciones Avanzadas

WildFly también permite una amplia personalización:

  • Añadir usuarios: Usa el script

    add-user.bat

    para añadir administradores, operadores y usuarios de la consola.
  • Despliegue automatizado: Copia tus aplicaciones en el directorio

    standalone/deployments

    para que WildFly las despliegue automáticamente al iniciar.

GlassFish

GlassFish es el servidor de referencia para Java EE. Ofrece soporte completo para todas las especificaciones de Java EE y es conocido por su robustez y facilidad de uso.

Requisitos previos

  • Java JDK: Debes tener instalado el JDK, preferiblemente la versión 8 o superior, que es compatible con GlassFish.
  • Variables de entorno: Configura las variables de entorno

    JAVA_HOME

    y

    GLASSFISH_HOME

    .

Pasos de Instalación

  1. Descarga GlassFish: Ve a la página oficial de GlassFish y descarga la última versión.
  2. Instalación: Extrae el archivo y ejecuta el instalador. Asegúrate de elegir las opciones predeterminadas para una instalación sencilla. 
    3. tar -xvzf glassfish-x.y.z.tar.gz
  3. Iniciar el servidor: Abre una terminal y ejecuta el siguiente comando para iniciar GlassFish: 
    4. asadmin start-domain
  4. Acceder a la consola: Abre tu navegador y visita

    http://localhost:4848

    .

Configuraciones Avanzadas

  • Crear usuarios: Utiliza el comando

    asadmin create-user

    para crear usuarios administrativos y operadores.
  • Despliegue de aplicaciones: Similar a los otros servidores, coloca tus archivos

    .war

    en el directorio

    domains/domain1/autodeploy

    .
